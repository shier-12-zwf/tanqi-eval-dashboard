## 1. 概述

本任务融合三类信号——**袭击事件时间线**、**海军部署态势**、**战争险费率与绕航量**——研判未来 1–3 个月海峡通行风险，并进一步分析信号间相关性/背离、通行风险三情景、能源与航运市场影响，产出未来 90 天先行指标观察清单。信源限英文＋阿拉伯文＋航运专业数据源（Lloyd's List、JMIC、克拉克森等）。

核心判定：任务所指「海峡通行风险」在 2026-09 已实质演变为**双海峡**风险——①霍尔木兹海峡（2026-02-28 起因美/以—伊朗战争被 IRGC 海军封锁，历经多轮关闭/重开/双重封锁）；②曼德海峡（胡塞 2026-09-11 夺取丕林岛 Perim，取得战略控制，形成对沙特航运的第二战线）。

**统计口径说明**：本报告为情报研判报告，无「漏洞」概念。核心产出为 3 项情景研判（基准/恶化/缓和，各附概率与可观测触发阈值），其余为三源基线量化事实、4 组信号相关性/背离结论、市场影响传导链与约 28 项先行指标。所有量化值均回锚到实际采集的来源（Baltic Exchange、Lloyd's List、JWC-LMA、Kpler、Blomberg/Reuters 转引、JMIC、USNI/CENTCOM、Alphaliner 等）与采集日期。

## 2. 目标与范围

- 目标（Intent）：融合三源信号，研判未来 1–3 个月海峡通行风险，产出三源信号基线、相关性/背离分析、三情景（基准/恶化/缓和各带概率与触发指标）、能源与航运市场影响、未来 90 天先行指标观察清单。
- 范围（Scope）：霍尔木兹海峡为主，红海/曼德海峡为第二战区，黑海作为系统性承保收缩的延伸对比。信源限英文＋阿拉伯文＋航运专业数据源（Lloyd's List、JMIC、克拉克森等）。
- 资产/对象（信息层面）：三源基线涉及袭击事件、海军/联军部署、战争险费率与绕航量，及其对油价、运价、运力、绕航格局的市场传导。
- 时间窗口：数据截至 2026-09-24；研判展望未来 1–3 个月（先行指标清单覆盖 2026-09-24 → 12-23）。

## 3. 核心研判发现（三情景）

> 三个情景为互斥的通行风险路径，概率相加为 100%。每条情景均附可观测触发/判定阈值，用于未来 90 天滚动校准概率。最可靠领先指标＝战争险费率/JWC 高风险区扩张；最危险背离＝集装箱「赌红海」与曼德安全恶化的同频背向。

### 情景 S-1（基准）：霍尔木兹「低通行、高成本、选择性放行」僵持态 — 概率 55%

| 概率 | 55% |
| - | - |
| 性质 | 既无大规模再升级、也无正式重开，僵持延续为「新常态」 |
| 关键参数 | 过境 10–30 艘/日；战争险 30–80 倍；JMIC 维持 SEVERE；基准租金 $450k–750k/日震荡；班轮 0 遇袭 |

原理：战争已持续 208 天，STS 穿梭油轮、陆桥、绕好望角等替代体系已「沉没成本＞逆转」，形成惯性；任何一方均无决定性破局能力。美军事压制（宣称打击 11000+ 目标、扫雷、封锁）与通行量长期背离，印证「军事压制≠通行恢复」。

### 情景 S-2（恶化）：三条升级路径 — 概率 30%

| 概率 | 30% |
| - | - |
| 路径 W1 | 霍尔木兹完全关闭（伊朗划定「禁区」升级为事实性封锁） |
| 路径 W2 | 胡塞首袭重返苏伊士/红海的班轮（相关性分析认定的「90 天最可能闪崩单点」） |
| 路径 W3 | 黑海＋红海＋霍尔木兹多海域系统性升级（多海域承保收缩） |

触发阈值：过境连续 3 日 ≤5 艘；首起班轮遇袭；战争险破 100 倍；JMIC 升 CRITICAL；美军航母 ≥4 艘；Brent 单周 ≥15%。概率依据：停火 9 月下旬破裂＋胡塞夺 Perim 与班轮赌红海同频背离＋黑海 JWC 全境扩区，显示风险泛化未止。

### 情景 S-3（缓和）：外交重开 — 概率 15%

| 概率 | 15% |
| - | - |
| 触发条件 | 新停火/MoU；过境回升 ≥60 艘/日；航母 3→1 艘；扫雷去雷完成；战争险 <15 倍；JMIC 降 HIGH；租金 <$400k/日 |

原理：6-17 MoU 先例证明外交可短时奏效；但「伊朗自述丢失已布雷位置」的水雷残留使物理重开技术门槛高、周期长（扫雷评估 40–50 天方恢复信心），故概率最低。

## 5. 信号间相关性与背离

- **背离·强（负相关）**：美军军事压制 vs 通行量未恢复——军事打击强度领先通行量 4 个月仍「失效」，机理为伊朗「丢失已布雷位置」的长期水雷残留＋选择性放行＋征费。
- **背离·极强·同频（负相关）**：集装箱重返苏伊士（9-14 Maersk/Hapag 迁回 AE5/AE11/AE12/ME2、9-16 OOCL Portugal 过河）vs 曼德安全恶化（胡塞 9-11 夺 Perim）。机理：绕好望角吸收 \~200 万 TEU 运力、亚欧周班需船 321→376 艘的成本压力迫使班轮「赌」红海，而胡塞当前打击集中沙特油轮、尚未攻击班轮。
- **同向扩散·滞后确认**：JWC 高风险区双线扩张——红海 7 月北移吉赞、黑海 9-18 扩至全境，均由攻击升级驱动、扩区滞后 4–8 周，又领先保费兑现。
- **正相关·费率领先**：战争险费率（40–60 倍）→ VLCC 单程 $20M、湾内/湾外租金差价（$728k vs $302k）→ STS 穿梭＋Yanbu→Ain Sukhna 北运＋DP World 陆桥化 +40%；费率领先绕航 1–4 周，绕航领先运价峰值约 +30 天。

## 6. 能源与航运市场影响

- **油价＝成本溢价而非供给硬缺口**：每桶 $7–8 直接计入战争险（保费→油价最硬证据），但 STS（9 月 \~650 万桶/日）＋Yanbu→Ain Sukhna 北运使「量」未断；Brent 呈线性成本溢价上涨，天花板取决于 STS 体系/北运走廊是否被定点打击。
- **真正「量」级硬缺口在黑海粮食**：俄乌占全球小麦贸易 >1/4、葵花籽油 2/3；70%+ 俄粮经黑海无替代弹性，为最被低估项（CSIS：黑海对小麦＝霍尔木兹对石油）。
- **运价极端结构分化**：油轮 $728k/日史上最高 vs 集装箱亚欧运价下行（Drewry WCI $4,465/FEU、上海→热那亚 -10%）；解释变量为运力供给刚性差异（油轮被 Sinokor 等少数风险容忍船东垄断 vs 全球箱队 3,400 万 TEU 历史过剩）。
- **绕航从「临时」转「结构性/不可逆」**：Jebel Ali 1H26 -60%（跌至全球第 32 位）、UAE 霍尔木兹依赖归零、DP World 卡车队 +40% 陆桥化。
- **最大尾部风险**：集装箱「赌红海」与曼德恶化同频背向，首起班轮遇袭将逆转苏伊士复苏；叠加黑海 JWC 全境升级＝多海域系统性承保收缩。

## 8. 其它结果（信源边界 / 阴性结果 / 未完成项）

- **信源边界限制（阴性结果，后续轮次无需重复尝试）**：任务点名的三家一手信源均无法直接抓取——Lloyd's List（Cloudflare 403 cf-mitigated）、JMIC 官网（jmic.info 域名无法解析 / jmic.com 仅探活 "OK"）、克拉克森 Clarksons（clarksons.net 403 / clarksons.com 数据产品付费墙）。UKMTO（403）、MSCHOA（连接失败）、CENTCOM（403）、Reuters（401）同样不可直连。上述一手源内容均经 gCaptain / Hellenic Shipping News 等二手转述获取。
- **阿拉伯文源边界**：Aljazeera.net 可达但搜索为 JS 渲染，静态抓取无文章列表，未直接取到阿拉伯文正文；已通过英文转发（Al Jazeera 引述）间接覆盖阿拉伯文区事件（如 9-24 德黑兰「开放霍尔木兹与接受条件挂钩」直播页 URL 已记录）。
- **未完成/受限项**：Lloyd's List / JMIC / 克拉克森一手数据未直连核实，相关量化值（如 40–60 倍、SEVERE 评级）均以二手转述为准，存在转述失真风险；阿拉伯文原文未能直接采集。
