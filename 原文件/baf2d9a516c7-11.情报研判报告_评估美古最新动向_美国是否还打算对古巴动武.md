### F-2：美国近期不太可能对古巴动武——六重障碍并存

| 定位 | r2 区域；研判性结论，非美方内部决策表态的实证 |
| - | - |
| 性质 | 基于可观察事实的外部推理，存在边界（无美决策层内部动武意向的直接证据） |

美国近期对古以「经济窒息为主、军事手段为辅」，动武非近期首要选项，存在六重障碍：

1. **经济窒息优先且已生效**——封锁目标为 2026 年底政权更迭，手段是燃料封锁 + 关税威胁 + 切断医疗出口收入而非入侵；美方措辞为「make a deal」「友好接管」（胁迫/谈判式），且窒息已奏效（5/14 能源耗尽、电网崩溃、抗议、旅游暴跌 58%），无军事必要性。
2. **外交渠道未断**——3/13 Díaz-Canel 公开确认谈判，经梵蒂冈斡旋释放 51 + 2000+ 政治犯（「善意姿态」），2/6 表态「愿无条件对话」，5/14 CIA 局长 Ratcliffe 在哈瓦那会晤，古方持续让步削弱动武正当性。
3. **缺乏可信直接挑衅借口**——5/17 无人机指控（300+ 俄伊无人机「密谋攻美」）被斥为「欺诈性案件/动武借口」；2/25 快艇事件俄方定性为「美侵略性挑衅」，美方否认参与并启动调查，缺乏 casus belli。
4. **俄罗斯介入风险**——俄持续供油（3/30 Anatoly Kolodkin 抵古、5/27 Universal 被拦），普京承诺继续供油，动武面临美俄在西半球对峙升级。
5. **国际人道成本与孤立**——OHCHR 报告婴儿死亡率升至 9.9‰、粮食减产 60%、药品仅 30%；中（8000 万美元 + 6 万吨大米）、墨、西、加、非盟等广泛声援古巴。
6. **国内政治约束**——古巴流亡反对派主张和平对话解决、警惕「被操纵」；佛州议员要求的是「独立调查」而非动武。

**边界说明：**&#x6E90;材料为维基式条目，无美决策层内部动武意向的实证表态，以上为基于可观察事实的外部障碍推理；特朗普确曾威胁对古动武(Time)且「军事干预选项始终在桌面」，动武未被永久排除，只是近期经济窒息 + 谈判路径优先。

### F-4：未来局势推演——四场景按可能性排序，动武为尾部场景

| 定位 | r4 区域；定性推演，源材料无成文「未来预测/专家研判」章节 |
| - | - |
| 性质 | 整合时间线事实的定性场景分析，非硬数据 |

**四个可能场景（按可能性排序）：**

1. **场景 A·持续封锁 + 外交施压蚕食（最可能，基线路径）**——美维持/升级经济窒息（已扩及 Visa/Mastercard、海外医疗任务、旅游，农业减产 60%、婴儿死亡率 9.9‰），以「2026 年底政权更迭」为目标但不直接动武，逼迫古巴内部更替或大规模移民外流。
2. **场景 B·外交缓和/交易达成（次可能）**——古巴以释囚 + 政治改革换放松封锁；支撑 = 3/13 谈判公开、4/3 释 2000+ 囚犯、3/30 俄油轮抵古时美「表现出更大灵活性」；障碍 = 9/8 声明「永远不再屈服于殖民统治、捍卫主权到最后结果」。
3. **场景 C·有限军事打击（中低可能）**——在「伊朗战争后」若无人机指控坐实或对美目标发生可信攻击，对古军事设施/领导层定点打击；支撑 = 美威胁「伊朗战争后攻击古巴」+ 密集侦察/无人机监视 + 300+ 攻击无人机指控。
4. **场景 D·全面入侵/政权更迭战争（低可能，门槛高）**——需重大挑衅借口 + 对古巴 11 万军队与俄可能军援的作战准备 + 占领后治理成本。

**两个动武触发器（叠加时风险升高）：**&#x2460; 伊朗战争结束后美释放军事资源；② 「古巴攻击美国」借口落地（无人机指控 5/17 与船事件 2/25，古方均斥为「伪造动武借口」）。古巴整体克制降低了即时冲突触发点，但能源/人道崩溃可能催生内部政权更替或移民危机，成为独立变量。
