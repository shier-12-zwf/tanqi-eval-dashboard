## 2. 目标与范围

- 目标（Intent）：基于开源情报（OSINT），定位当前每一艘在役美军航母的具体活动位置，做到逐艘覆盖、无遗漏。
- 范围（Scope）：11 艘在役航母（Nimitz 级 10 艘 + Ford 级 1 艘），区分部署/维修/训练/母港停靠状态，逐艘给出当前点位与置信度；在役在建舰不追踪活动位置。
- 授权：任务授权书（AUTHORIZATION.md）确认 operator 授权对范围内 OSINT 对象开展主动探测与信息采集，生效时间 2026-09-24 06:18:25 UTC。
- 核心信源：USNI News「Fleet and Marine Tracker」（周更，逐舰位置）、USNI News 单篇报道、Wikipedia（舰载机名录 / 舰史）、VesselFinder / MarineTraffic（AIS，受限）。
- 排除/受限：navy.mil 官方 fact-file 与 nvr.navy.mil 舰籍数据库当前不可达（WAF 拦截 / DNS 无法解析）；AIS 商业站对匿名用户拦截或限流，未能取得坐标级实时位置。

## 4. 其它结果

- **未服役在建舰（不追踪活动位置）**：CVN-79 John F. Kennedy（海试中，交付推迟约 2027，8/19 报道船上发生凶杀案）、CVN-80 Enterprise（在建约 2030）、CVN-81 Doris Miller / CVN-82 Clinton / CVN-83 George W. Bush（已订购/建造）。
- **坐标级定位受限（阴性结果）**：MarineTraffic 对匿名用户返回 403；myshiptracking /fleet/aircraft-carriers 路径 404；VesselFinder 虽可达（200）但未能取得匿名坐标级 AIS 数据接口。故 3 艘海上部署航母仅有「大区海域 + 最近港口访问」级定位，无实时经纬度。
- **官方信源不可达（阴性结果）**：navy.mil 官方 fact-file 与 nvr.navy.mil 舰籍数据库当前不可达（Akamai/edgesuite WAF 403 或 DNS 无法解析）；cusnc.navy.mil、surfpac.navy.mil、cnic.navy.mil 连接失败(000)。无法取 NAVSEA 官方交付公告。
- **未完成项**：r6 最终交叉校验（Oracle p\_659b392e）在任务结束时仅完成信源复核与 tracker 追查，**尚未产出最终的 carrier\_final\_r6.md conclusion 文件**；AIS 坐标级交叉印证未完成。本报告已基于各 oracle 已落盘结论汇总，可视为 r6 的替代性交付。
- **时效性边界**：09-21 为当前最新一期 Fleet Tracker（09-28 期在 09-24 探索时点尚未发布）；母港停靠类航母的最新状态取自 tracker 早先各期 + 单篇新闻，last observed 截至 09-14 tracker。
