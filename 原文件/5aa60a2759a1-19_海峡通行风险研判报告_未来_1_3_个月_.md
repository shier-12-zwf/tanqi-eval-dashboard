## 二、信号间相关性与背离分析

### 2.1 正相关传导链

    袭击频次 ↑ ──→ 战争险费率 ↑ ──→ 绕航比例 ↑
         │                                    │
         └──── 海军部署密度 ↑ ←──────────────┘
                  （拦截对冲）

- **袭击 → 保费**：滞后 3–7 天；每次造成船体损伤的袭击驱动费率跳升 10–20 bps。
- **袭击 → 绕航**：滞后 1–2 周（运营决策周期）；当前处于高基线，边际弹性递减。
- **海军部署 → 拦截率**：正相关但受弹药补给瓶颈约束；SM-2 / Aster 库存消耗 > 补给时出现拐点。

### 2.2 关键背离（Divergence Signals）

| # | 背离现象 | 描述 | 风险含义 |
|---|---------|------|---------|
| 1 | 红海袭击烈度 ↑ vs. 保费未同步突破 | 近 30 天烈度上升，费率在 0.7%–1.0% 震荡未破 1.2% | 市场已部分定价持续冲突；**但首艘大型商船沉没或重大伤亡将触发非线性跳升** |
| 2 | 霍尔木兹军事活动 ↑ vs. 保费持平 | IRGC 演训增加，战争险市场未反应 | **最大背离**：市场假设伊朗不会关闭海峡（伤及自身出口），该假设在极端情景下可能失效 |
| 3 | 绕航固化 vs. 运力紧张缓解 | 绕航维持高位，但新造船交付 + 降速航行部分对冲 | 运力缓冲收窄；绕航再升 5–8 ppt 将出现二次运力缺口 |
| 4 | 阿语媒体叙事升级 vs. 实际袭击未同步放大 | Al-Masirah 威胁升级，但打击频次未同比放大 | 可能为谈判筹码 / 威慑信号；但误判风险上升 |

### 2.3 相关性矩阵（定性估计）

## 三、通行风险情景分析（90 天窗口）

### 情景 A：基准 —「持续消耗，有限通行」

| 维度 | 内容 |
|------|------|
| **概率** | **55%** |
| **红海 / 曼德** | 胡塞维持每周 2–4 起袭击；偶发饱和攻击被拦截；无商船沉没或重大伤亡 |
| **霍尔木兹** | IRGC 维持灰色地带施压；无海峡关闭或重大袭击 |
| **战争险费率** | 红海 0.7%–1.2%；霍尔木兹 0.10%–0.20% |
| **绕航比例** | 维持 65%–72% |
| **触发/维持条件** | ① 停火/外交无实质突破 ② 胡塞弹药补给维持但未升级 ③ 无重大伤亡事件 |

### 情景 B：恶化 —「多海峡联动升级」

| 维度 | 内容 |
|------|------|
| **概率** | **25%** |
| **红海 / 曼德** | 袭击升至每周 5–8 起；出现 **商船沉没或 ≥3 名船员死亡**；胡塞使用新型反舰巡航导弹或布设水雷 |
| **霍尔木兹** | 以伊冲突外溢；IRGC 实施"有限封锁"（选择性拦截、水雷、FAC 蜂群）；至少 1 起油轮遇袭 |
| **战争险费率** | 红海 **> 1.5%**（部分保险人拒保）；霍尔木兹跳升至 **0.5%–1.0%** |
| **绕航 / 替代** | 红海绕航 > 80%；霍尔木兹出现管道分流（沙特东西管道、Habshan–Fujairah 利用率 > 80%） |
| **触发指标** | ① 以–伊直接军事冲突升级 ② 胡塞获新型反舰武器 ③ 海峡出现水雷 ④ 商船重大伤亡 ⑤ 美/英对胡塞实施 > 50 目标大规模打击 |

### 情景 C：缓和 —「外交突破，逐步回归」

| 维度 | 内容 |
|------|------|
| **概率** | **20%** |
| **红海 / 曼德** | 也门停火 / 沙–胡塞谈判实质进展；袭击降至每周 0–1 起；CMF 拦截任务缩减 |
| **霍尔木兹** | 伊核谈判或地区缓和降低对抗；IRGC 活动回归常态 |
| **战争险费率** | 红海回落至 0.3%–0.5%；霍尔木兹维持 0.10% |
| **绕航比例** | 3 个月内降至 45%–55%（完全回归需 6–12 个月） |
| **触发指标** | ① 也门全面停火协议 ② 胡塞公开声明停止袭击 ③ 联合国/阿曼斡旋突破 ④ TOP 3 船公司宣布红海复航 |

## 四、对能源与航运市场影响

### 4.1 能源市场

| 情景 | 原油（Brent） | 天然气（LNG） | 成品油 |
|------|-------------|-------------|-------|
| **基准** | +$1–3/桶风险溢价维持；无供给中断 | 卡塔尔 LNG 正常出口；欧洲现货影响有限 | 新加坡–鹿特丹价差因绕航小幅扩大 |
| **恶化** | **+$8–15/桶**（霍尔木兹受限）；管道可分流 ~6.5 Mbd 但备用产能不足 | 卡塔尔 LNG 中断风险 → 欧洲 TTF **+30%–50%** | 中东炼厂出口受阻；亚洲裂解价差走阔 |
| **缓和** | 风险溢价收窄 −$2–4/桶 | 影响有限 | 物流成本下降传导滞后 4–6 周 |

> **关键数据**：霍尔木兹日均原油通过量 ~**20–21 Mbd**（全球供给 ~20%），~80% 运往亚洲。曼德海峡日均 ~4–5 Mbd + 大量成品油与 LNG。
> **信源**：EIA, IEA OMR, OPEC MOM, Kpler / Vortexa。

### 4.2 航运市场

| 板块 | 基准 | 恶化 | 缓和 |
|------|------|------|------|
| **集装箱（亚–欧）** | 运力损失 ~10%–12%；运价高于危机前 80%–120% | 运力损失 > 15%；SCFI 再涨 30%–50% | 6–12 个月逐步回归 |
| **油轮（VLCC）** | 中→亚航线正常；运费受需求驱动 | 运费 **翻倍+**；管道分流增加陆上瓶颈 | 回归季节常态 |
| **干散货** | 影响有限 | 间接：燃油成本 + 保险传导 | 轻微利好 |
| **船舶保险（H&M / P&I）** | 红海附加费高位；P&I 拒保条款扩展 | 红海出现"不可保"区域；战争除外条款援引 | 附加费逐步取消（6–12 月） |
| **船员 / 人力** | 航次 +10–14 天 → 疲劳与合同压力 | 安全风险 → 拒绝红海航次 → 用工成本 ↑ | 缓解 |

> **信源**：Clarksons Research; Drewry; BIMCO; Alphaliner; Lloyd's List; International Group of P&I Clubs。
